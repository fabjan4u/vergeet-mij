> ⭐️ **Vind je dit een nuttig initiatief?** Geef dit project een **ster** op GitHub! Daarmee help je meer burgers en consumenten hun digitale privacyrechten eenvoudig op te eisen.

## ⚡ Kenmerken

- **100% Privacy & Client-side**: Nul tracking, geen server die data opslaat. Alle namen en e-mails blijven puur in jouw lokale browser.
- **Database van 35+ bedrijven**: Directe DPO/Privacy-adressen voor Bol.com, Coolblue, Albert Heijn, Ziggo, Basic-Fit, Uber, Meta, Google, Spotify, Klarna en meer.
- **Vrij invoerbaar**: Staat een bedrijf er niet tussen? Typ de bedrijfsnaam en het e-mailadres in en de brief wordt direct klaargezet.
- **3 Juridische Hefbomen**:
  1. **Art. 17 AVG (Gegevenswissing / Recht om vergeten te worden)**: Verplichte vernietiging van account, profiel en trackingdata + melding aan derden (Art. 19).
  2. **Art. 15 AVG (Inzageverzoek)**: Opvragen wat het bedrijf over jou weet, inclusief gratis kopie.
  3. **Art. 21 AVG (Bezwaar / Marketingstop)**: Onmiddellijk verbod op direct marketing, nieuwsbrieven en profilering.
- **Juridische tanden**: Verwijst naar de formele wettelijke 30-dagen termijn (Art. 12 lid 3 AVG) en boetes via de Autoriteit Persoonsgegevens (AP).
- **Proportionaliteit**: Voorkomt dat bedrijven onnodig om een kopie van je paspoort vragen (Art. 12 lid 6 AVG).
- **1-Klik Acties**:
  - `🚀 Open in Mailapp`: Vult direct ontvanger, onderwerp en tekst in via `mailto:`.
  - `📋 Kopieer Brief`: Voor webformulieren of webmail.
  - `💾 Download .txt`: Om lokaal te bewaren of als bijlage mee te sturen.
- **📅 30-Dagen Agenda-herinnering**:
  - `📅 Download .ics`: Werkt op iPhone/Apple Calendar, Android, Outlook en Thunderbird.
  - `🌐 Google Agenda Link`: Direct toevoegen aan Google Agenda in de browser.
  - Bevat direct de link naar het klachtenloket van de Autoriteit Persoonsgegevens (AP) om zonder vertraging een boeteverzoek in te dienen als het bedrijf niet reageert!
- **Meertalig**: Schakel eenvoudig tussen Nederlands en Engels.

## 🚀 Starten

Navigeer naar de map en start de ontwikkelserver:

```bash
cd vergeet-mij
npm run dev
```

Of bouw de geoptimaliseerde productiebundel:

```bash
npm run build
npm run preview
```
